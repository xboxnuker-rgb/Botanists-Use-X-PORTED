## Install

1. Close Schedule I.
2. Remove legacy Fortis DLLs and older Botanists Use X DLLs from the game's `Mods` folder.
3. Extract the chosen DLL into `Schedule I/Mods`.
4. Use `BotanistsUseX.dll` by itself, or install either/both individual DLLs. Never mix the combined and individual layouts.
5. In multiplayer, use the same DLL layout and version on the host and every client.
6. Launch the game and confirm the blue GSVS startup banner appears.

## What changed

- Ported both legacy mods from the removed `PotActionBehaviour` API to current grow-container behaviors.
- Added the combined `BotanistsUseX.dll` with independent soil-pourer and sprinkler toggles.
- Added configurable 1–8 bag soil-pourer capacity, persistent charges, manual/botanist top-ups, proportional fill visuals, and one-charge dispensing.
- Made botanists carry the selected seed and plant immediately after using a loaded pourer.
- Added idle-window pourer preparation and correct refill navigation.
- Added small and large sprinkler activation with immediate worker release.
- Added host-authoritative charge/capacity synchronization, remote interactions, staged visuals, and join-in-progress state.
- Added blue GSVS startup identity banners with port/creator wording and original-author credit.
